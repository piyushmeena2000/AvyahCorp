# Prompting Rules

## Purpose
This document defines standards for Prompting Rules.

## Objectives
- Maintain production quality.
- Reuse existing code.
- Prefer minimal verified changes.
- Preserve accessibility, responsiveness, and performance.

## Required Workflow
1. Inspect existing implementation.
2. Search the project.
3. Read related files.
4. Make the smallest change possible.
5. Verify functionality.
6. Check responsive behavior.
7. Ensure no regressions.

## Do
- Reuse existing architecture.
- Follow project conventions.
- Keep code clean and maintainable.

## Don't
- Guess.
- Hallucinate.
- Duplicate code.
- Break existing functionality.

## Verification
- No console errors
- No broken layouts
- No regressions
- Production-ready output

> Expand this document with project-specific standards as your project evolves.
