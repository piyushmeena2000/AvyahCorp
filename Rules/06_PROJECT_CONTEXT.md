# Project Context

## Project Name

AvyahCorp Shopify Store

---

# Mission

Build a premium Shopify experience that feels modern, trustworthy, fast, and conversion-focused.

Every improvement should increase usability, visual quality, and performance while preserving the existing architecture.

---

# Brand Personality

Premium

Minimal

Modern

Confident

Trustworthy

Energetic

Clean

Professional

Never make the website feel cheap, cluttered, or overly playful.

---

# Design Philosophy

Less is more.

Whitespace is intentional.

Typography should be clear.

Layouts should breathe.

Content should be easy to scan.

Every section should feel visually balanced.

---

# User Experience Goals

Users should immediately understand:

Who we are.

What we sell.

Why they should trust us.

How to purchase.

Navigation should always feel effortless.

---

# Color System

Always use the project's existing brand colors.

Do not introduce new primary colors.

Do not use random gradients.

Maintain strong contrast and readability.

---

# Typography

Follow the existing font family.

Maintain hierarchy:

H1

↓

H2

↓

H3

↓

Body

↓

Caption

Never introduce inconsistent font sizes or weights.

---

# Components

Maintain consistency across:

Header

Navigation

Buttons

Cards

Badges

Forms

Footer

Icons

Every component should look like it belongs to the same design system.

---

# Product Cards

Always maintain:

Equal height

Equal spacing

Consistent image ratio

Readable pricing

Clear CTA

Consistent hover effect

Never stretch product images.

Never distort packaging.

---

# Header

The header is one of the most important components.

Preserve:

Sticky behavior

Navigation

Logo placement

Cart functionality

Search functionality

Mobile menu

Never redesign the header without approval.

---

# Animations

Animations should be:

Fast

Smooth

Minimal

Purposeful

Premium

Avoid unnecessary movement.

Avoid distracting effects.

---

# Mobile Experience

Mobile is equally important.

Every change must be verified on:

Desktop

Tablet

Mobile

Touch interactions must remain smooth.

---

# Performance Goals

Minimize JavaScript.

Reuse existing assets.

Avoid unnecessary requests.

Keep layouts lightweight.

Maintain fast page loads.

---

# Accessibility

Maintain sufficient color contrast.

Use semantic HTML.

Preserve keyboard navigation.

Do not reduce accessibility for visual changes.

---

# Editing Philosophy

Before making changes:

Understand the existing implementation.

Reuse existing code.

Modify only what is necessary.

Keep changes as small as possible.

---

# Things Never To Do

Never redesign pages unless requested.

Never replace existing branding.

Never duplicate sections.

Never duplicate snippets.

Never invent assets.

Never invent file paths.

Never invent selectors.

Never guess.

---

# Success Criteria

Every completed task should:

Feel native to the project.

Maintain consistency.

Improve quality.

Preserve performance.

Avoid regressions.

If uncertain, stop and ask instead of guessing.
