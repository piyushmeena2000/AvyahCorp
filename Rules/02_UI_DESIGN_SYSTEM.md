# UI Design System

## Mission

Build premium, modern, minimal, production-ready interfaces.

Every new component must match the existing design system.

Never create random designs.

---

# Visual Style

Modern

Minimal

Premium

Clean

High-end

Professional

---

# Colors

Always use existing brand colors.

Never invent new colors.

Primary Color:
Crimson Red

Text:
Black
Dark Gray

Background:
White
Light Gray

Accent:
Only use existing brand accent colors.

Never introduce random gradients.

---

# Typography

Follow the existing font family.

Preserve typography hierarchy.

Heading

↓

Subheading

↓

Body

↓

Caption

Never randomly change font weights.

Never mix font families.

---

# Spacing

Maintain consistent spacing.

Use an 8px spacing system.

Examples

8px

16px

24px

32px

40px

48px

64px

Never use inconsistent spacing.

---

# Border Radius

Reuse existing border radius.

Never introduce different corner styles.

---

# Shadows

Keep shadows subtle.

Never use heavy shadows.

Never use colored shadows.

---

# Icons

Use only one icon style across the website.

Icons must have:

Same size

Same stroke weight

Same visual style

Never mix outlined and filled icons.

---

# Buttons

Buttons should have

Consistent height

Consistent padding

Consistent radius

Consistent typography

Consistent hover animation

Never redesign existing buttons unless requested.

---

# Cards

Every card should have

Equal padding

Equal radius

Equal spacing

Equal shadow

Equal typography

Consistent image ratio

Never make one card visually different from the others.

---

# Images

Never stretch images.

Never distort aspect ratio.

Maintain image quality.

Keep image sizes consistent.

---

# Animations

Animations should be

Smooth

Fast

Subtle

Premium

Never flashy.

Never distracting.

Never over-animate.

---

# Mobile

Every change must work on

Desktop

Tablet

Mobile

Never break responsiveness.

---

# Accessibility

Maintain readable contrast.

Maintain keyboard accessibility.

Maintain proper spacing.

Maintain touch targets.

---

# UI Consistency

Before creating any component

Compare it with existing components.

Reuse existing styles whenever possible.

Do not invent new patterns.

---

# Final Verification

Before finishing

Check

✓ Alignment

✓ Spacing

✓ Colors

✓ Typography

✓ Icons

✓ Shadows

✓ Radius

✓ Responsive Layout

✓ Accessibility

Only return code after all checks pass.
