# PROJECT.md

# Project Overview

## Project Name

AvyahCorp Shopify Store

---

# Mission

Build a premium D2C Shopify website that communicates trust, quality, and modern design while maximizing conversion rate.

The website should feel comparable to premium brands like Apple, Nothing, Stripe, Vercel, and high-end D2C food brands.

Every change should improve the customer experience while preserving performance and maintainability.

---

# Header Requirements

Header is one of the highest priority components.

Requirements:

Sticky

Smooth Reveal

Hide on Scroll Down

Reveal on Scroll Up

No flickering

No layout shift

No resizing

No jump animations

Desktop and Mobile must behave consistently.

---

# Product Cards

Product cards should always maintain:

Equal Heights

Equal Padding

Equal Image Ratio

Equal CTA Placement

Equal Typography

Equal Hover Animation

Never stretch product images.

Never distort packaging.

---

# Buttons

Buttons should feel premium.

Consistent height.

Consistent radius.

Consistent spacing.

Consistent hover effects.

Never create random button styles.

---

# Icons

Use a single icon family.

Consistent stroke width.

Consistent alignment.

Consistent sizing.

Never mix icon styles.

---

# Typography

Maintain hierarchy.

Heading

Subheading

Body

Caption

Never introduce random font sizes.

Never introduce random font weights.

---

# Colors

Always use the existing brand color system.

Never introduce new primary colors.

Never invent gradients.

Never use colors that conflict with the brand.

---

# Animations

Animations should feel:

Premium

Fast

Smooth

Purposeful

Subtle

Never over animate.

Never use template style fade-ins.

---

# Performance Goals

Fast First Paint

Efficient CSS

Keep Lighthouse scores high whenever possible.
